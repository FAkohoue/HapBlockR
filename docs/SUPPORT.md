# Support

Use the [GitHub issue
tracker](https://github.com/FAkohoue/HapBlockR/issues) for reproducible
bugs and documentation problems. Use a discussion forum or institutional
quantitative-genetics support channel for study design, breeding-policy
choices, and interpretation that is specific to confidential programme
data.

Before requesting support, record the package version,
[`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html), input
dimensions, random seed, selected method, validation output, and the
complete warning or error message. Replace real identifiers and values
with a synthetic example whenever possible.
